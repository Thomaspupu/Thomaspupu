### 🎯 Projet en vedette

**🚚 Monsieur Croques** - Plateforme de commande en ligne pour un foodtruck de croque monsieurs (en cours de dev).
`React` `TypeScript` `Node.js` `MySQL`

Une application web complète permettant de commander des produits en ligne avec :
- Menu interactif et intuitif
- Système de commande en temps réel
- Localisation du foodtruck
- Paiement en ligne sécurisé
- Gestion de compte utilisateur avec historique de commandes
- Programme de fidélité personnalisé

Mon premier projet fullstack mettant en pratique l'ensemble de ma stack technique.
